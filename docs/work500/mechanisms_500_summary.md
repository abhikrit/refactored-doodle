## 1. Method

| Step | What was done |
|---|---|
| Extraction | Script over L1 §6 and the 24 chapters: file paths (incl. brace groups and `path:Member` lists), line references (`File.cs:n-m`, incl. comma-continued ranges), dotted names (`Type.Member`, permission/template/resource names, plugin system names), interfaces and class names by suffix, `*Async` methods, lower-case setting keys, and `Controller` + action words (actions kept only if the method exists in either version). 3331 tokens in total. |
| Resolution | Index of both trees (type declarations with namespace, string literals, `$"{nameof(X)}.Y"` permission constants, locale resources, plugin.json system names). Members compared by declaration signature (async keyword ignored) and attributes; type-level public API diffed; method bodies diffed with braces normalised; line references re-anchored by line text. |
| Review | All body diffs of cited methods read manually; behaviour changes the PRD relies on set to Changed (listed in §4); cosmetic body changes kept Same with the change described in the note. Wildcards, framework types and runtime files resolved by hand (evidence in CSV). |
| Exclusion | 995 tokens matched nothing in either version (product-defined names: IC/event codes such as `Order.StageChanged`, `Log.*` messages, product permissions `Orders.Core.*`, `Payments.Core.*`, `Security.Core.*`, new entities/settings such as `egovsettings.*`, prose words). They are not nopCommerce mechanisms and are not in the CSV. |

Status: **Same** = exists, signature/attributes unchanged, behaviour the PRD relies on unchanged (cosmetic body changes noted). **Changed** = exists but signature, attributes, location, API surface, behaviour or line number differs. **Removed** = present in 4.90.8, absent in 5.00.1. **Not found** = absent in both (only the 4.70-only names the PRD itself says are gone).
